# Primary Source Research

Use this skill when an answer depends on current external information, precise source
attribution, an unfamiliar system, or a claim that should not rely on memory. Prefer
maintainer documentation, specifications, source code, release notes, standards, and
original research over summaries and search-result snippets.

## Define the question

State the decision the research must support and the relevant version, date, environment,
and constraints. Separate factual questions from recommendations so evidence and judgment
remain distinguishable.

## Gather evidence

1. Search for primary sources using terminology from the system itself.
2. Open the supporting page, file, or paper; do not cite the search result as evidence.
3. Check publication and event dates, supported versions, scope, and deprecation status.
4. Use multiple independent primary sources when a conclusion crosses product boundaries
   or when sources could reasonably disagree.
5. Capture the URL and the specific claim it supports while researching.

If only secondary evidence is available, label that limitation. Do not fill gaps by
presenting inference as sourced fact.

## Synthesize

Lead with the answer relevant to the decision. Cite each time-sensitive or non-obvious
claim near the sentence it supports. Explain conflicts, uncertainty, and assumptions, and
clearly mark conclusions inferred from multiple sources.

Quote only when exact wording matters; otherwise paraphrase faithfully. Finish with the
practical consequence or next decision rather than a bibliography dump.
